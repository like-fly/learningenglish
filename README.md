# English Learning Project

这是一个由 Codex 协助维护的长期英语学习项目。当前重点是建立稳定、可测量的阅读能力；之后再扩展到综合英语、雅思和移民场景。

## 现在开始

在 Codex 中打开本项目，然后发送：

> 开始今天的学习

Codex 会读取 [教师规则](AGENTS.md)、[当前状态](state/current.md)、最近两次学习记录和到期词汇，只给出今天需要完成的内容。完成回答后，Codex 会批改并更新记录。

当你说“结束今天的学习”，或当天任务已经批改并记录完成后，Codex 会提交本次学习产生的文件变更，并推送到当前分支的远程仓库。当前默认远程为 `origin/main`；推送失败时会保留本地提交并说明原因。

如果今天很累，可以发送：

> 今天只做最低任务

最低任务只需约 5 分钟。断档后不补课、不清零，直接从当前任务恢复。

## 常用指令

- `开始今天的学习`：标准 20 分钟学习。
- `今天只做最低任务`：约 5 分钟的恢复任务。
- `继续上次没做完的任务`：从中断位置继续，不新开记录。
- `结束今天的学习`：保存当前进度，提交本次学习变更并推送到远程仓库。
- `查看我的进步`：根据原始记录汇总趋势，不凭印象评价。
- `进行阶段复盘`：通常每完成 5 次学习后执行。
- `调整学习计划`：依据最近数据修改难度、材料或节奏。

## 原则

1. 完成比完美重要，最低任务也算有效学习。
2. 不用连续天数制造压力，以完成次数和能力变化判断进步。
3. 生词不是越多越好，只保留影响理解或可能复现的词。
4. 先作答，再看讲解；先理解文章，再研究语法。
5. 不复制新闻全文，只保存链接、必要短摘录、个人回答和教师反馈。
