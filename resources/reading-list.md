# Reading Resources

## 使用规则

- 优先选择新闻、社会、教育、城市、工作与公共生活主题。
- 每篇记录标题、URL、预计难度、词数、使用日期和效果，不复制全文。
- 初始材料应能在 8–10 分钟内读完；根据连续两次表现调整难度。
- 标记状态：`candidate`、`used`、`too_easy`、`too_hard`、`retired`。
- 外部资源可能更新或失效，使用当天由 Codex 检查链接和内容。
